# Kalm website

The public pages for the Kalm Android app (the app's own repository is separate).

- Landing page: https://shih-vaa.github.io/kalm-legal/
- Privacy policy: https://shih-vaa.github.io/kalm-legal/privacy.html

Served by GitHub Pages from the `docs/` folder of `main`. `docs/index.html` is the landing page and
`docs/privacy.html` the privacy policy. Both are plain HTML with no scripts, no fonts and no outside requests.

Please keep the name of this repository: the privacy policy address is built into the app and given to
Google Play, and renaming the repository would change it.
